# Обучение Go в Нетологии

Репозиторий с практическими заданиями, домашними работами и проектами, выполненными в рамках обучения языку программирования Go на платформе [Нетология](https://netology.ru/).



## Структура репозитория

```text
.
├──  Рефакторинг программы по принципам SOLID/
├──  Практическое задание многопоточный обработчик/
├──  Практическое задание Создание REST API‑сервиса (CRUD задач)/          
```


## Как запустить проект

Для работы с кодом потребуется установленный [Go](https://go.dev/dl/).

Проверить установку Go можно командой:

```bash
go version
```

Чтобы запустить отдельное задание:

```bash
cd путь/к/заданию
go mod init названия проекта # инициализировать модуль
go mod tidy #установить зависимости
go run .
```

Чтобы запустить тесты:

```bash
go test ./...
```
