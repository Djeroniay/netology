## Как запустить проект

Для работы с кодом потребуется установленный [Go](https://go.dev/dl/).

Проверить установку Go можно командой:

```bash
go version
```

Чтобы запустить отдельное задание:

```bash
cd путь/к/заданию
go run .
```

Чтобы запустить тесты:

```bash
go test ./...
```
