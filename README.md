# Обучение Go в Нетологии

Репозиторий с практическими заданиями, домашними работами и проектами, выполненными в рамках обучения языку программирования Go на платформе [Нетология](https://netology.ru/).

## О курсе

В процессе обучения я изучаю:

- основы языка Go;
- переменные, типы данных и операторы;
- условные конструкции и циклы;
- функции;
- массивы, срезы и карты;
- структуры и методы;
- интерфейсы;
- обработку ошибок;
- работу с файлами;
- основы многопоточности;
- горутины и каналы;
- тестирование Go-приложений;
- создание небольших проектов на Go.

## Как запустить проект

Для работы с кодом потребуется установленный [Go](https://go.dev/dl/).

Проверить установку Go можно командой:

```bash
go version
```

Чтобы запустить отдельное задание:

```bash
cd путь/к/заданию
go run .
```

Чтобы запустить тесты:

```bash
go test ./...
```
